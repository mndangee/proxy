proxy 실행 방법
================

1. ZIP 파일의 압축을 완전히 풉니다.
2. proxy.app과 open.mac.command가 같은 폴더에 있는지 확인합니다.
3. open.mac.command를 더블클릭합니다.
4. Terminal 창이 열리면 proxy.app이 자동으로 실행됩니다.

주의
----
- 이 패키지는 Apple Developer ID로 공증된 정식 배포본이 아닌 사내·테스트용 빌드입니다.
- arm64 패키지는 Apple Silicon(M1 이상), x64 패키지는 Intel Mac용입니다.
- 출처를 신뢰할 수 있는 패키지인지 확인한 뒤 실행하세요.
- 회사 보안 정책이 Terminal 스크립트 실행을 차단하면 관리자에게 문의하세요.
